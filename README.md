## CN2、CN2 GT、CN2 GIA 有什么区别

CN2 是中国电信的高端骨干网（AS4809），和大家常说的「普通线路」163 骨干网（AS4134）是两套网络。但商家嘴里的「CN2 VPS」还分两档，买错档是新手最常踩的坑。

**CN2 GT（Global Transit）**：去程走普通 163，回程走 CN2。属于入门级直连，比纯 163 好，但高峰期去程照样会堵。

**CN2 GIA（Global Internet Access）**：去程回程都走 CN2，而且是优先级最高的那条。拥堵时 GIA 流量有更高优先权，体感上就是晚高峰基本不掉速。

落到数字上，差距很直观：普通线路晚高峰延迟普遍 300ms 起，丢包率可以冲到 10% 以上；CN2 GIA 到美西电信用户平均 150–165ms，到欧洲（法兰克福）三网平均 160–180ms，丢包接近零。中欧之间物理距离摆在那，160–180ms 已经是这条线路能压到的极限。
